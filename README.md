# Portfolio — Your Name

This repository is a personal portfolio site built for GitHub Pages. It serves a static site from the repository root (index.html) and includes project pages and supporting documentation.

## Quick preview

- Serve locally: `python -m http.server 8000` and open `http://localhost:8000`

## Deploy / Publish

- For a user site: name the repo `your-username.github.io` and publish from the `main` branch (root).
- This repo includes a Pages Actions workflow; pushing to `main` triggers an automatic deploy.

## Contents

- `index.html`, `styles.css`, `script.js` — main site files
- `projects.md`, `about.md`, `teaching-plan.md`, `citation.md` — site pages
- `.github/workflows/pages.yml` — GitHub Actions Pages workflow

## Contributing

Edit the markdown pages or update `index.html`. Open a PR to merge changes into `main`.
