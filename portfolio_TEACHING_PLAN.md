Teaching plan: GitHub & portfolio for humanities students (3 sessions)

Goals:
- Teach basic Git/GitHub workflows
- Show how to publish a simple portfolio and share reproducible work
- Build confidence using Copilot to scaffold HTML/CSS and helpful prompts

Session 1 — Intro to GitHub (90 min)
- Concepts: repo, commit, branch, PR, README, license
- Exercise: create account, initialize repo, push a README

Session 2 — HTML + GitHub Pages (90 min)
- Explain static site, Pages, and assets
- Exercise: customize index.html (name, bio, one project)
- Use Copilot prompts: "Generate a short bio paragraph for a scholar in X"

Session 3 — Reproducibility & Ethics (90 min)
- FAIR data, licensing, citation, sensitive content
- Exercise: add CITATION.md, LICENSE, and a small reproducible notebook

Assessment & artifacts:
- Each student publishes a personal portfolio with 1 reproducible project, README, and CITATION.md

Notes for instructors:
- Emphasize plain-language READMEs and accessible demos for non-technical audiences
- Encourage use of permissive licenses when sharing code and data; discuss exceptions
