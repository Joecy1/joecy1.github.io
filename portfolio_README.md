Starter portfolio scaffold — copy these files into a new GitHub repo and enable Pages

Files in this artifact (copy to repo root):
- index.html (rename from portfolio_index.html if needed)
- styles.css (portfolio_styles.css)
- script.js (portfolio_script.js)
- projects.md
- TEACHING_PLAN.md
- CITATION.md
- .github/workflows/pages.yml (see pages workflow file in this folder)

Quick local preview:
- Run a simple HTTP server in the folder (Python: python -m http.server 8000) and open http://localhost:8000/index.html

Deploy to GitHub Pages:
1. Create repo named your-username.github.io (for user site) or any repo and use Pages.
2. Push files, then enable Pages from branch "main" / root or use the included Actions workflow.

Using Copilot:
- Prompt Copilot to refine sections, add ARIA attributes, or produce project tiles from a projects.json file.

License & citation: add LICENSE and CITATION.md to state reuse terms.
